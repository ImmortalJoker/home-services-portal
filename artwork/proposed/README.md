## Reproduce the preview

From the repository root on macOS, run `open artwork/proposed/preview.html`, or open that file directly in a browser. Keep it next to the two SVGs. Each image loads the named source by relative filename at the labeled display dimensions. The page needs no server, scripts, or remote resources.

Verify source identities and preview references with Python 3 and Git.

```sh
python3 -c 'from hashlib import sha256; from pathlib import Path; print(*(f"{sha256(p.read_bytes()).hexdigest()}  {p}" for p in sorted(Path("artwork/proposed").glob("*.svg"))), sep="\n")'
python3 tests/lic03_artwork_test.py -v
```

Set `LIC03_GIT` to a Git executable path if the default `git` launcher is unavailable.
