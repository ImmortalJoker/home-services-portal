Third-party notices
===================

The project license in LICENSE does not replace the licenses of third-party
components. Retain the applicable copyright notices and license texts when
redistributing those components, including in built distributions.

Distribution locations
----------------------

Source texts: LICENSE (project MIT), this NOTICE (including the React runtime
MIT text below), and src/assets/fonts/OFL-*.txt (full font copyright notices
and OFL texts). Static copies are kept in public/LICENSE.txt,
public/NOTICE.txt and public/licenses/OFL-*.txt, respectively.

Both Vite builds copy these to dist/LICENSE.txt, dist/NOTICE.txt and
dist/licenses/OFL-*.txt. In the public Pages build they are reachable under
the configured base path (by default /home-services-portal/), for example
/home-services-portal/LICENSE.txt and /home-services-portal/NOTICE.txt.
The font notices are under /home-services-portal/licenses/ using the
OFL filenames listed below.

The Authentik Docker runtime includes the same files in /app/dist/ and
serves them at /LICENSE.txt, /NOTICE.txt and /licenses/OFL-*.txt.
